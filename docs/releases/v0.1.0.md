好好说的第一个公开版本：按住说话，松开就是一段干净的文字。

## 下载

下载下方的 `BetterVoiceInput-Setup-0.1.0.exe` 并运行。安装在当前用户目录，不需要管理员权限。

- 系统要求：Windows 10 / 11（64 位）、麦克风、网络连接。
- 程序暂未进行代码签名。如果 Windows 提示“Windows 已保护你的电脑”，点击“更多信息”→“仍要运行”。
- 可用 `BetterVoiceInput-Setup-0.1.0.exe.sha256` 核对下载文件是否完整。

## 主要功能

- 按住 `Alt+X` 说话，松开后自动整理并输入到光标处，支持聊天软件、文档、浏览器和终端，不会自动按回车。
- 去掉口头禅、结巴和无意义的重复，听懂“九点，不对，十点”这样的改口，保留否定、强调和不确定的表达。
- 声音在本机识别，只把识别出的文字发给你选择的 AI 服务（默认 DeepSeek，也支持其他兼容 OpenAI Chat Completions 的服务）。
- 三个本地语音模型可一键下载和切换：SenseVoice（默认，中文）、X-ASR（中英混说）、Canary 180M Flash（英文）。可以选择模型保存位置。
- 个人词库、原文与结果对照、导入录音、本机加密历史（默认关闭）、开机自启动。

## 第一次使用

1. 打开“设置”，填写 AI 服务的 API 地址、API Key 和模型名称。
2. 点击“下载语音模型”（约 240 MB，只需一次）。
3. 在 Windows 隐私设置中允许桌面应用使用麦克风。

完整说明见 [使用指南](https://github.com/hyt0019/better-voice-input/blob/main/docs/USER_GUIDE.md)。

## 已知限制

- 以管理员身份运行的软件、远程桌面等可能限制自动输入，此时可按 `Alt+V` 补输或复制结果。
- 单次录音最长 2 分钟。
- 整理文字需要联网并会产生所选 AI 服务的费用。
