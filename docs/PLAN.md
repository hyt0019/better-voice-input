# 实施与验收

每个里程碑完成相应检查后提交并推送到 origin/main。

1. 文字整理：独立的 DeepSeek 客户端、结构化输出、修改依据与保护检查、CLI、回归测试、真实 Key 验证。
2. 本地识别：SenseVoice int8 模型下载、音频文件解码、静音过滤、分段识别，验证用户提供的 m4a。
3. 桌面输入：PySide6 桌面应用、麦克风录音、托盘、录音浮窗、快捷键、原文对照、词库、凭据保存、焦点检查和取消。
4. 交付：端到端验证、界面截图检查、Windows 可执行文件、安装/使用/故障说明。

## 界面设计

以“好好说”为工作名称，整个窗口是一张可编辑的语音草稿。上方深色录音卡片是视觉焦点，中间原文/整理结果两张白色卡片并列，下方明确的复制和输入操作。设置、语音模型和历史采用独立对话框，不挤占正文。

- 暖白底 #F5F4F0，卡片 #FFFFFF，边线 #E6E2DA，正文 #17211F，辅助文字 #6B7673，主色深青 #0E7C86，录音色 #EF5F57。
- 录音卡片使用深青渐变与柔光，圆形麦克风按钮在录音时变为停止键并带扩散波纹，音量以滚动声纹显示；状态胶囊区分就绪、录音中、处理中和已整理。
- 字体：微软雅黑 UI；图标使用 Windows 自带的 Segoe Fluent Icons，不额外打包图片。按钮、输入框和卡片统一圆角，开关替代复选框。
- 录音浮窗为不抢焦点的深色圆角胶囊，带状态指示点和声纹。
- 左对齐，文本区随窗口缩放；长路径中间省略。原文和整理结果同等可访问，错误信息提供下一步操作。

## 边界

第一版针对 Windows 10/11 x64、普通话及少量中英混说，单次录音最多 120 秒。录音达到上限时明确结束并处理已录内容。未经过真人/真实目标软件验证的兼容性如实标注。

SenseVoice 分段识别不是逐字流式识别。首版结束录音后提交完整转写；跨次修改已插入文字不在本版范围。

语义检查是启发式保护，不是正确性证明。发现疑点时保留原文和预览，不以模型自报置信度决定自动输入。

## 验收

覆盖结巴、重复、改口、跨句更正、真正的否定、强调、引用、未确定事项、数字和人名。单独报告 ASR 误差与整理误差。测试取消、静音、网络失败、迟到结果、焦点变化和重复插入保护。

隐私文件、Key、模型、虚拟环境和输出录音不进入提交。发布前检查暂存区与历史中的敏感内容。
