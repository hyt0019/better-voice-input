# 好好说 · 使用说明

## 启动

本机已安装语音模型并配置好密钥。双击 `启动好好说.cmd` 后程序在系统托盘运行，点击麦克风图标可以打开主窗口和设置。

**日常使用：点击目标输入框 → 按住 `Alt+X` 说话 → 说完松开 → 等待识别和整理，文字自动输入。** 不需要打开主窗口，也不需要再次确认。录音和处理时仅显示一个不抢焦点的小状态条。

便携程序位于 `dist/BetterVoiceInput/BetterVoiceInput.exe`，整个 BetterVoiceInput 文件夹需保持完整。直接运行 exe 会显示主窗口；加 `--background` 可在配置就绪时仅在托盘运行。

首次在其他电脑运行：

1. 打开“设置”，填写自己的 DeepSeek API Key 并保存。密钥进入 Windows 凭据管理器。
2. 点击“下载语音模型”，约 240 MB；下载文件会校验完整性。
3. 选择麦克风。Windows 设置 → 隐私和安全性 → 麦克风，需要允许桌面应用访问。
4. 点击普通文本输入框，按住 `Alt+X` 说话，说完松开。等待整理完成后自动输入。

默认仅保存当前会话。关闭主窗口会缩小到托盘，右键托盘图标选择“退出”才会结束程序。

## 录音和输入

- 停顿不会自动结束，可以慢慢想、重复和改口。单次最长 2 分钟，到上限会处理已经录下的内容。
- 默认开启“按住快捷键说话，松开结束”和自动输入。设置中可更换双键组合，也可切回按一次开始、再按一次结束。
- 全局快捷键录音时会记住目标输入位置。录音和整理期间不要切换窗口、点击其他位置或继续键入；位置变化时保留结果，回到所需输入框按 `Alt+V` 补输。
- 点击主窗口录音或导入文件，只展示结果。需要输入时点击“输入到其他窗口”，在 3 秒内点击目标输入框；或切到目标后按 `Alt+V`。
- 疑点默认保留在主窗口中，不中断自动输入。需要先核对时，在设置中开启“有疑点时暂停自动输入，留待核对”。即使暂停或出错，也不会自动弹出主窗口；点击托盘图标查看详情。
- 按 `Esc` 取消正在进行的任务。网络出错等情况会保留已有原文，可打开主窗口重试。
- 程序不会自动按回车发送。终端窗口采用手动复制，避免多行粘贴被当作命令。
- 自动粘贴会暂用剪贴板，在未被用户修改时尝试恢复原内容。特殊应用异步读取剪贴板时，必要时使用“复制结果”。

## 原文、词库和历史

左侧是原始识别，右侧是整理结果，二者都可在任务结束后编辑。原文修改后点击“整理文字”可重新处理。

在词库中每行添加一个常见人名、项目名或英文术语。例如常用人名、DeepSeek、产品名称。词库用于整理阶段辅助拼写，不保证修复所有识别错误，不应让模型猜测未说出的事实。

默认不保存录音或历史。可在设置中主动开启文字历史；内容使用 Windows 当前用户加密，最多 100 条、保留最近 7 天（访问或新增历史时清理过期记录）。关闭历史开关停止新增，已有记录可通过“历史 → 清空全部历史”删除。

## 数据位置

- 设置：`%LOCALAPPDATA%/BetterVoiceInput/settings.json`，不包含密钥。
- 可选加密历史：同目录 `history.json`。
- 模型：优先使用设置中的 `model_dir`，其次是可执行文件旁的 `models`；从项目 `dist/BetterVoiceInput` 运行时也会查找项目根目录的 `models`。最后使用上述用户目录下的 `models`。本机模型已安装在项目根目录，不需要再次下载。
- Key：Windows 凭据管理器，服务名 `better-voice-input`；开发测试还可使用 `DEEPSEEK_API_KEY` 或项目根目录的 `deepseek api key.txt`。
- 音频在本机识别。转写和相关词库通过 HTTPS 发送至 DeepSeek，需要联网且账户有余额。

## 常见问题

**人名或英文识别错了**：检查原文，添加词库或手动修改后重新整理。尤其“不是，是五千”如果被识别成“不是五千”，应核对数字，程序会提示这种歧义。

**快捷键没反应**：可能已被其他程序占用，在设置中更换。也可以点击开始录音。

**无法插入**：点击目标普通文本框后按 `Alt+V`。管理员程序、自定义控件、远程桌面等可能限制模拟输入，使用复制结果即可。

**下载或 API 连接失败**：检查网络及代理。支持标准 `HTTPS_PROXY` / `HTTP_PROXY` 环境变量；不要把代理凭据或 API Key 写入仓库。程序不会自动上传音频到其他服务。

**模型下载中断**：重新点击下载；已完成且通过校验的文件会复用，未完成文件重新下载。

**出现 SmartScreen 提示**：本地打包程序尚未购买代码签名证书，可从源码复现构建；不要通过关闭系统防护解决。

## 验证范围

详见 `docs/VALIDATION.md`。已验证用户示例音频、本地识别、真实 API、界面与任务状态。自动化环境无法取得前台窗口焦点，真实麦克风录音以及微信/Word/浏览器等跨窗口兼容性仍需交互桌面试用。

## 开发命令

```powershell
.\.venv\Scripts\python.exe -m better_voice_input.app
.\.venv\Scripts\python.exe -m better_voice_input.cli download-models --directory models
.\.venv\Scripts\python.exe -m better_voice_input.cli transcribe '录音.m4a' --clean --output private/result.json
.\.venv\Scripts\python.exe scripts/evaluate_text.py
.\scripts\build.ps1
```

文本评测会调用真实 API 并计费，普通 pytest 不会访问网络或读取测试 Key。
