## 2026-10-04：文字与音频管线

- 34 项离线测试通过：接口错误、取消、截断、结构化输出、数字/否定/不确定性、音频重采样、长度限制和模型校验。
- 使用用户授权的测试 Key 调用 DeepSeek；测试密钥和响应中的个人内容未提交。
- SenseVoice int8 239,233,841 字节，词表 315,894 字节，VAD 643,854 字节。下载文件通过固定摘要校验。
- 用户提供的 75.61 秒 M4A 完成本地解码和识别：含模型加载约 2.08 秒；整理约 2.34 秒。这是单次测量，不是延迟保证。
- 真实录音中时间、地点、平台、收件人和快捷键更正生效，否定与日期不确定性保留。

音频和完整转写保留在被忽略的本地目录，仓库只记录方法和结果摘要。
